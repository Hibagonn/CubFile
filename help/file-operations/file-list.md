# ファイル一覧の見方

## この機能でできること

開いているフォルダの中のファイルとフォルダを確認し、操作したい項目を選びます。

## 操作前の準備

サイドバーかアドレスの移動で、見たいフォルダを開きます。

## 操作手順

1. 項目を1つクリックすると、その項目が選択されます。
2. Ctrl を押しながらクリックすると、離れた項目を追加できます。
3. Shift を押しながらクリックすると、範囲を選べます。
4. Ctrl+A で、そのパネルの項目をすべて選べます。文字を入力している最中は、文字の選択が優先されます。
5. 右クリックで、コピーや名前の変更などのメニューが開きます。

## 操作中の画面

[![ファイル一覧でメモ.txtを1件選んだ状態です。](../images/file-selected.webp)](../images/file-selected.webp)



**表示 > 表示形式** で、詳細、アイコン、リストを切り替えられます。詳細では、名前以外の情報も列で見られます。

## 完了の確認方法

選んだ項目が強調されていれば、次のコピーや削除の対象になっています。

## 注意事項

隠しファイルを出すかは、**設定 > 一般** の「隠しファイル・フォルダーを表示する」で切り替えます。

## よくあるトラブル

期待したファイルが見えないときは、開いているフォルダが違っていないか、隠しファイルの設定、表示の更新（F5）を確認します。
