# 削除

## この機能でできること

選んだファイルやフォルダを削除します。

## 操作前の準備

消してよいか、名前と場所を確認します。必要なら、先に別のフォルダへコピーを残します。

## 操作手順

1. 削除する項目を選びます。
2. 右クリックの **削除**、または Delete キーを押します。
3. 確認ダイアログが出たら、対象を読んでから進めます。

確認を出すかは、**設定 > ファイル操作** の「削除前に確認ダイアログを表示」です。

## 操作中の画面

確認ダイアログに、削除する対象が出ます。複数選んでいるときは、件数を確認します。

## 完了の確認方法

一覧からその項目が消え、必要なら F5 で表示を更新しても戻らないことを確認します。

## 注意事項

削除は元に戻しにくい操作です。確認をオフにしていると、Delete キーですぐ消えます。共有フォルダや LAN の相手側を開いているときは、消える場所が自分の PC ではないことがあります。

## よくあるトラブル

削除できないときは、ファイルが他のアプリで開いていないか、フォルダへの権限があるかを確認します。メッセージが出た場合は、その文章を読んでから再試行します。
