# フォルダ移動

## この機能でできること

見ている場所を、別のフォルダ、親フォルダ、ドライブ一覧へ移します。

## 操作前の準備

青い枠が、移動したいパネルに付いていることを確認します。

## 操作手順

1. サイドバーの場所をクリックして開きます。
2. 一覧のフォルダをダブルクリックして、その中へ入ります。
3. Alt+↑ で親フォルダへ戻ります。
4. Alt+← で履歴を戻り、Alt+→ で進みます。
5. F5 で、今のフォルダを読み直します。
6. PC やドライブの一覧へ戻る操作は、ショートカット一覧の「PC/ドライブ一覧」からも割り当てられます。

## 操作中の画面

パネルに、今のフォルダの中身が表示されます。別のパネルは、それぞれの場所を覚えています。

## 完了の確認方法

開きたいフォルダの名前と、一覧の中身が一致していれば移動できています。

## 注意事項

前回のフォルダを次回起動時に復元するかは、**設定 > 一般** の項目です。

## よくあるトラブル

開けない場所では、権限や、ドライブが接続されているかを確認します。ネットワーク上の場所は [ネットワークドライブ](../network/network-drives.md) も見てください。
