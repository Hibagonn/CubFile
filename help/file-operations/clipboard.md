# クリップボード

## この機能でできること

コピーや切り取りの内容を貼り付けます。CubFile には、コピーした項目を後から選び直すクリップボードの一覧もあります。Free と Plus のどちらでも使えます。

## 操作前の準備

貼り付け先のフォルダを開き、青い枠を付けます。

## 操作手順

1. ファイルをコピー（Ctrl+C）または切り取り（Ctrl+X）します。
2. 貼り付け先で Ctrl+V を押します。
3. 過去にコピーした内容を見るときは、**ツール > クリップボード** を開きます。
4. パスだけをコピーする、名前だけをコピーする操作は、右クリックまたはショートカット設定にあります。

## 操作中の画面

クリップボードのパネルに、保持している項目が並びます。そこから貼り付けたい内容を選べます。

## 完了の確認方法

貼り付け先のフォルダに、選んだ項目が現れます。

## 注意事項

文字を入力している欄では、Ctrl+V はファイルではなく文字の貼り付けになります。ファイルを貼りたいときは、入力欄からフォーカスを外します。

## よくあるトラブル

Windows の他のアプリでコピーしたファイルも、貼り付けの対象になることがあります。意図した内容かを、貼り付け前にクリップボードパネルで確認できます。
