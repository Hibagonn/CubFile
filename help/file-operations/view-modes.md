# 表示形式

## この機能でできること

ファイルの並びを、詳細、アイコン、リストに切り替えます。

## 操作前の準備

切り替えたいパネルに青い枠を付けます。

## 操作手順

1. **表示 > 表示形式** を開きます。
2. **詳細**、**アイコン**、**リスト** のいずれかを選びます。
3. ショートカットを割り当てている場合は、そのキーでも切り替えられます。初期状態では、これらの表示切替に専用キーは付いていません。

## 操作中の画面

詳細は列で情報を見ます。アイコンは絵で見ます。リストは名前を詰めて見ます。

## 完了の確認方法

選んだ形式のチェックが付き、一覧の見た目が変わります。

## 注意事項

アイコンの絵そのものを変える設定は [アイコン](../settings/icons.md) です。表示形式とは別です。

## よくあるトラブル

アイコンを変えたのに絵が古いときは、CubFile の再起動が必要です。表示形式の切り替えだけなら、再起動は不要です。
