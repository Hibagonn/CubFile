# 名前の変更

## この機能でできること

ファイルまたはフォルダの名前を1つ変えます。

## 操作前の準備

使う文字に、Windows で使えない記号が含まれていないことを確認します。

## 操作手順

1. 項目を1つ選びます。
2. 右クリックの **名前の変更**、または F2 を押します。
3. 新しい名前を入力します。
4. Enter で確定します。やめるときは Esc です。

## 操作中の画面

名前の入力欄が出ます。拡張子（末尾の `.txt` など）も名前の一部です。変えると、開くアプリが変わることがあります。

## 完了の確認方法

一覧の名前が、入力した名前になっていれば完了です。

## 注意事項

同じフォルダに同じ名前は置けません。複数のファイルを規則でまとめて変えるときは [一括リネーム](batch-rename.md) を使います。

## よくあるトラブル

名前を変えられないときは、そのファイルを開いているアプリを閉じるか、読み取り専用や権限を確認します。
