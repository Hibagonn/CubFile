# 移動

## この機能でできること

選んだファイルやフォルダを、別の場所へ移します。移したあとは、元の場所からはなくなります。

## 操作前の準備

移動先のフォルダを開き、書き込めることを確認します。練習は、大事でないファイルで行います。

## 操作手順

1. 移動したい項目を選びます。
2. 右クリックの **切り取り**、または Ctrl+X を選びます。
3. 移動先のフォルダを開き、そのパネルを選択します。
4. **貼り付け**、または Ctrl+V を選びます。

一覧から別のパネルへドラッグして移すこともできます。ドラッグしたときの既定の動作は、**設定 > ファイル操作** のドラッグ＆ドロップで確認できます。

## 操作中の画面

同じドライブの中では短時間で終わることがあります。別のドライブへ移すときは、コピーしてから元を消す動きになり、進捗が出ることがあります。

## 完了の確認方法

移動先に項目があり、元のフォルダからなくなっていれば完了です。

## 注意事項

**設定 > ファイル操作** に、「移動時に進捗を優先する」があります。有効にすると、同じドライブの移動でもコピーしてから削除する動きになります。途中で止めたときの残り方に影響します。

## よくあるトラブル

元のファイルが残っているときは、移動が完了していないか、コピーとして扱われた可能性があります。進捗とログを確認してから、残ったファイルを消してください。
