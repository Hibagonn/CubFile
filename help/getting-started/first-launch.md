# 初回起動

## この機能でできること

初めて CubFile を開いたとき、フォルダを見て、ファイルを選ぶところまで進めます。

## 操作前の準備

[インストール](installation.md) が終わっていること。練習用のフォルダと、中に数個のファイルがあると操作しやすいです。大切なファイルで試す必要はありません。

## 操作手順

1. `CubFile.exe` を起動します。
2. 左側のサイドバーで、開きたい場所をクリックします。
3. 青い枠のパネルが、今選ばれているパネルです。
4. ファイルを1つクリックして選びます。
5. 言語を変えるときは、**ツール > 設定** の **一般** で日本語または英語を選び、適用します。

## 操作中の画面

メインウィンドウに、メニュー、ツールバー、サイドバー、ファイルの一覧が出ます。設定は **ツール > 設定** から開きます。

## 完了の確認方法

サイドバーで選んだ場所の中身が、パネルに表示されていれば完了です。

## 注意事項

- 前回終了時のフォルダを次回も開くかは、設定の **一般** にある「前回終了時のフォルダー状態を復元する」で決まります。
- ヘルプを開いても、CubFile は終了しません。オンラインヘルプは既定のブラウザが開きます。
- 起動のたびに更新を確認する設定にしていると、更新の確認が走ることがあります。これはヘルプの表示とは別です。

## よくあるトラブル

ウィンドウが出ないときは、タスクバーに CubFile が残っていないか確認します。別の Windows セッションで起動している場合は、そのセッションの CubFile を使います。新しいウィンドウは開きません。
