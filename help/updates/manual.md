# 手動更新

## この機能でできること

ブラウザから更新プログラムを入手し、自分で実行します。

## 操作前の準備

[GitHub Releases](https://github.com/Hibagonn/CubFile/releases) を開きます。

## 操作手順

1. 最新のリリースを開きます。
2. すでに CubFile を使っている場合は、`CubFile-<バージョン>-Updater.exe` をダウンロードして実行します。
3. 新しくフォルダへ置く場合は、`CubFile-<バージョン>-win64.zip` を展開し、中の `CubFile.exe` を起動します。
4. `CubFile-<バージョン>-win64.zip.sha256` は、ZIP の整合性確認用です。実行ファイルではありません。
5. Source code (zip) と Source code (tar.gz) は実行用ではありません。

## 操作中の画面

Updater はウィザードに沿ってファイルを入れ替えます。完了後に CubFile が起動します。

## 完了の確認方法

**ヘルプ > バージョン情報** のバージョンが、ダウンロードしたリリースと一致することを確認します。

## 注意事項

Vector で配布されているパッケージも、同じ公開版です。Free 用と Plus 用の別 ZIP はありません。

## よくあるトラブル

Updater が「ファイルを置き換えられない」という意味のメッセージを出すときは、CubFile のフォルダが読み取り専用でないか、セキュリティソフトが実行を止めていないかを確認します。ZIP を展開しただけの場合は、古いフォルダの `CubFile.exe` を起動し続けていないかを確認します。
