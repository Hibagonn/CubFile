# 振り分け

## この機能でできること

ファイル名などの条件に合わせて、ファイルをフォルダへ振り分けます。条件の編集と実行は Plus です。Free のメニューには「振り分け (Plus)」のように表示されます。

## 操作前の準備

振り分け先のフォルダを決めます。条件が1つもない状態では実行できません。

## 操作手順

1. **ツール > 振り分け > 振り分け条件設定** を開きます。
2. 条件のセットと、一致したときの移動先を作ります。
3. 設定を保存します。
4. 振り分けたいフォルダをパネルで選びます。
5. そのフォルダに対する振り分けを実行します。メニューやツールバーに、選択フォルダ内のファイルを振り分ける操作があります。
6. 条件をファイルで保管するときは、**ファイル** メニューの「振り分け条件を JSON で書き出し」と「JSON から読み込み」を使います。

転送予約の行では、チェックを入れるとその予約に振り分けを適用できます。

## 操作中の画面

条件設定は専用の画面です。実行中は進捗ウィンドウに「振り分け」と出ることがあります。

## 完了の確認方法

条件に合ったファイルが移動先にあり、進捗が完了していることを確認します。合わないファイルは元の場所に残ります。

## 注意事項

次のメッセージが出たら、実行前の条件が足りていません。

- 振り分けキーワードルールがありません。
- 振り分け条件セットがありません。
- 振り分け先フォルダが存在しません。

振り分け先が無いときは、フォルダを作ってからもう一度実行します。
