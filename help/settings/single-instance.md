# 重複起動

## できること

同じ Windows ユーザーでは、CubFile を1つだけ起動します。2回目に起動すると、新しいウィンドウは作らず、開いている CubFile を前面に出します。

## 設定項目はない

オンとオフの設定はありません。常に1つです。エディションが Free でも Plus でも、インストール場所が違っても、同じユーザーの中では共有します。

別の Windows ユーザー、別の PC は、それぞれ自分の CubFile を起動できます。

## 2回目の起動で起きること

- 開いているウィンドウを前面に出せたときは、メッセージは出ません。
- 別の Windows セッションで起動しているときは、「CubFileは別のWindowsセッションで起動しています。」と出て、このセッションでは起動しません。
- ウィンドウを前面に出せなかったときは、「ウィンドウを前面に表示できませんでした。タスクバーのCubFileを確認してください。」と出て、新しくは起動しません。
- 起動状態を確認できなかったときも、新しくは起動しません。

## 対象外のプログラム

更新用の `CubFileUpdater.exe`、配布物の Updater、ライセンス発行ツールは、この制限の対象外です。更新の処理は CubFile 本体の起動制限に含まれません。

フォルダ監視の補助起動や、ビルド情報の表示も、通常のウィンドウ起動とは別に動きます。

## 注意

タスクマネージャーに CubFile が残っていると、新しいウィンドウは出ません。反応しないときは、タスクバーを確認し、必要ならそのプロセスを終了してから起動します。
