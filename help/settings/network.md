# ネットワーク設定

## できること

LAN 転送の有効化、ポート、デバイス名、信頼済みの相手、共有フォルダを設定します。Free と Plus のどちらでも使えます。

[![ネットワーク設定です。LAN転送はオフです。名前と受信先は見本です。](../images/settings-network.webp)](../images/settings-network.webp)

## 開き方

**ツール > 設定 > ネットワーク**。F1 でこのページを開きます。

## 項目

- **LAN転送を有効にする**
- **このPCをほかのデバイスの検索結果に表示する**
- **相手PCから操作されたとき通知する**
- **デバイス名**
- **ポート**（初期値 45820）
- **受信ファイルをSHA-256で検証する**
- 受信先フォルダ
- **信頼済み端末**（検索、IP 指定での追加、再ペアリング、接続テスト、すべて解除）
- **共有フォルダ**
- LAN アクティビティと転送履歴

有効なときは「LAN転送: 有効（待ち受けポート …）」と表示されます。

## 注意

共有フォルダは、渡してよい場所だけにしてください。接続テストの成功メッセージは「接続に成功しました。」です。失敗時は「接続に失敗しました。」または、オフラインか IP が変わった可能性を示す文章が出ます。
