# クラウドストレージ

## できること

対応するクラウドストレージのフォルダを、サイドバーから開けるようにします。LAN の CubFile 同士の転送とは別の機能です。

## 開き方

**ツール > 設定 > クラウドストレージ**。アプリ内ヘルプガイドにも「クラウドストレージ」の項目があります。

## 項目

CubFile は Google Drive、OneDrive、Dropbox へ直接ログインしません。各サービスの公式デスクトップアプリが Windows に公開している場所を使います。

1. 公式アプリをインストールし、ログインして、エクスプローラーからフォルダを開ける状態にします。
2. CubFile の **設定 > クラウドストレージ** を開きます。
3. **クラウドストレージを検索** または **再検索** を押します。
4. 左のサイドバーに出したい項目の **表示** をオンにします。
5. **OK** または **適用** を押します。

表示をオフにしても、ファイルは削除されません。クラウドからログアウトもしません。サイドバーから隠れるだけです。

## 注意

クラウドの同期フォルダは、通信状況によってファイルが未ダウンロードのことがあります。開けるまで時間がかかる、またはプレースホルダーだけに見えるときは、公式アプリ側の状態を確認します。

設定データの保存先を、この同期フォルダへ移す必要はありません。標準の設定場所はローカルです。
