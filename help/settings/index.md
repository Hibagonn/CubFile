# 設定

**ツール > 設定**、または Ctrl+コンマで開きます。左の一覧でページを切り替え、**OK** または **適用** で反映します。設定画面で F1 を押すと、開いているページのオンラインヘルプをブラウザで開きます。ショートカットを入力している欄では、F1 はその欄のキーとして扱います。

- [パネル](panels.md)
- [表示](view.md)
- [ファイル操作](file-operations.md)
- [クラウドストレージ](cloud.md)

- [アーカイブ](archive.md)

- [アイコン](icons.md)
- [重複起動](single-instance.md)

通常の保存場所は `%LOCALAPPDATA%\CubFile\config` です。**ファイル > データ保存先を変更** で場所を移せます。OneDrive など同期フォルダへの保存は、標準では避けます。
