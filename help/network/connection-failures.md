# 接続できないとき

ファイルを消す操作はせず、次の順で確認します。

## 両方で起動しているか

相手の PC で CubFile が起動している必要があります。相手の画面で、すでに CubFile が開いていないかも確認してもらいます。同じ Windows ユーザーでは、CubFile は1つだけ起動します。

## LAN転送が有効か

**設定 > ネットワーク** の「LAN転送を有効にする」を、両方で確認します。状態が「LAN転送: 無効」のときは、検索にも転送にも出ません。

## 同じネットワークか

ゲスト用 Wi-Fi や、隔離された LAN では互いが見えません。Windows のネットワーク設定で、同じネットワークにいるかを確認します。

## ポート

既定は 45820 です。どちらかだけ番号を変えていると接続できません。両方を同じ番号に戻してから、もう一度接続テストをします。

## ファイアウォール

CubFile の通信がブロックされていると、検索にも接続テストにも失敗します。初回起動時に Windows が確認を出していた場合は、プライベートネットワークでの通信を許可します。

## 検索に出さない設定

「このPCをほかのデバイスの検索結果に表示する」がオフの相手は、検索一覧に出ません。その場合は **追加（IP指定）** を使います。IP が変わったときは、メッセージ「オフラインか、IPが変わっている可能性があります。」に従い、再ペアリングします。

## 共有フォルダ

接続できてもフォルダが空のときは、相手の共有フォルダが未設定か、権限が足りない状態です。
