# ネットワークドライブ

## この機能でできること

Windows に割り当てたネットワークドライブや、エクスプローラーから見える共有を、CubFile のパネルで開きます。これは、CubFile 同士の LAN 転送とは別の経路です。

## 操作前の準備

Windows で、そのドライブや共有にアクセスできることを、エクスプローラーで先に確認します。

## 操作手順

1. CubFile のサイドバー、または PC とドライブの一覧から、そのドライブを開きます。
2. フォルダの中へ進み、必要なファイルを選びます。
3. コピーや移動は、ローカルのフォルダと同じ操作です。

## 操作中の画面

パネルの場所が、ネットワークのパスやドライブ文字になっていれば、そこを見ています。

## 完了の確認方法

エクスプローラーで見るのと同じファイルが、CubFile の一覧に出ていれば開けています。

## 注意事項

ネットワークドライブは、Windows の接続が切れると CubFile からも開けなくなります。CubFile の「LAN転送を有効にする」とは独立です。

クラウドストレージの入口は、サイドバーと **設定 > クラウドストレージ** にあります。手順は [クラウドストレージ](../settings/cloud.md) です。

## よくあるトラブル

ドライブが見えないときは、Windows にログオンし直すか、エクスプローラーで「ネットワークドライブの割り当て」を確認します。CubFile だけを再インストールしても、Windows の割り当ては戻りません。
