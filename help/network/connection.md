# 接続の確認

## この機能でできること

相手の CubFile と通信できるかを、ファイルを送る前に確認します。

## 操作前の準備

両方で CubFile を起動し、LAN転送を有効にしておきます。

## 操作手順

1. **設定 > ネットワーク** を開きます。
2. 状態の文章を読みます。有効なときは「LAN転送: 有効（待ち受けポート …）」と出ます。
3. **デバイスを検索** で、同じ LAN の CubFile を探します。
4. 見つかった相手、または **追加（IP指定）** で登録した相手に対して **接続テスト** を押します。
5. 成功のメッセージが出ることを確認します。

## 操作中の画面

信頼済み端末の一覧に、名前、状態、自動接続、接続先が並びます。接続先にはアドレスとポートが出ます。この画面を人に見せるときは、アドレスが写り込まないようにしてください。

## 完了の確認方法

「接続に成功しました。」または、詳細の成功メッセージが出れば確認できています。

## 注意事項

検索結果に自分を出したくないときは、「このPCをほかのデバイスの検索結果に表示する」を外します。外したあとも、IP を指定すれば接続を試みられます。

## よくあるトラブル

「接続できませんでした。オフラインか、IPが変わっている可能性があります。」と出たときは、相手の CubFile が起動しているか、IP アドレスが変わっていないかを確認し、必要なら再ペアリングします。
