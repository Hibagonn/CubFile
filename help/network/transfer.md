# LAN転送

## この機能でできること

選んだファイルを、同じ LAN の CubFile へ送ります。Free と Plus のどちらでも使えます。

## 操作前の準備

[接続の確認](connection.md) が成功していること。相手が受け取るフォルダを共有していること。

## 操作手順

1. 送りたいファイルを選びます。
2. **ツール > CubFileへ送る** を選びます。
3. 相手と、送り先を指定します。
4. 開始します。
5. 相手の共有を Remote Panel で開いているときは、そのパネルをコピー先にして貼り付ける方法でも開始できます。

## 操作中の画面

転送中は進捗ウィンドウで、進み具合とエラーを確認できます。ウィンドウを閉じても、進捗側で処理が続く場合があります。そのときは進捗ウィンドウから CubFile を再表示できます。

## 完了の確認方法

進捗が完了になり、相手のフォルダにファイルがあることを確認します。

## 注意事項

受信時のハッシュ検証を有効にしていると、大きいファイルでは完了まで時間がかかります。検証に失敗したときは、ファイルを開かずに、もう一度送り直してください。

LAN差分回収（未取得のファイルだけを集める機能）は Plus です。通常の送信とはメニューが分かれています。

## よくあるトラブル

始まらないときは、相手の共有権限、貼付モード、LAN転送の有効、接続テストを順に確認します。
