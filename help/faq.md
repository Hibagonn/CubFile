# よくある質問

## CubFile は何をするアプリですか

Windows でフォルダを並べ、コピー、移動、名前の変更、削除を行うファイル管理アプリです。検索、圧縮、同じ LAN の CubFile への送信、転送予約も使えます。

## インストールは必要ですか

専用のインストーラーはありません。`CubFile-<バージョン>-win64.zip` を展開し、`CubFile.exe` を起動します。

## F1 で何が開きますか

メイン画面では、既定のブラウザでこのオンラインヘルプが開きます。設定画面では、開いている設定ページの説明が開きます。ショートカットを入力中の欄では、F1 はそのキーの指定に使われます。

インターネットに接続できないときは、**ヘルプ > ヘルプガイド** の画面内の説明を使います。ガイドを開いたまま、フォルダの操作を続けられます。

## ヘルプを開くと CubFile は通信しますか

ヘルプを開いたときだけ、ブラウザがこのサイトを開きます。起動のたびにヘルプサイトへ接続する処理はありません。

## 設定はどこに保存されますか

通常は `%LOCALAPPDATA%\CubFile` です。エクスプローラーのアドレス欄にその文字列を入力すると開けます。以前ドキュメントフォルダに残っている設定は、起動時にローカルへコピーします。コピーできない場合は、以前のファイルを残したまま上書きしません。

## Free と Plus は別のソフトですか

いいえ。公開版は1つのプログラムです。ライセンス登録と再起動で Plus になります。更新ファイルも共通です。

## 同じ PC で2つ起動できますか

同じ Windows ユーザーではできません。2回目は、開いているウィンドウを前面に出します。別の PC では、それぞれ起動できます。

## 貼り付けてもファイルが増えません

ツールバーが予約貼付になっていないか確認します。予約貼付のときは [転送予約](network/reservation.md) に入ります。

## (Plus) と出るメニューは使えますか

Free では使えません。登録と再起動の手順は [ライセンス登録](licensing/license.md) です。

## オンラインヘルプがブラウザで開きません

アドレスをコピーするボタンが出ます。コピーしたアドレスを、ブラウザのアドレス欄へ貼り付けてください。サイトをまだ GitHub Pages で公開していない場合は、ページは開けません。公開手順は配布元の説明にあります。
